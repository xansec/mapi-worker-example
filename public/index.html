Testing an internal API?

Quick tunnel:

Simply run

cloudflared tunnel \
          --url http://localhost:PORT

And paste the generated

https://<random>.trycloudflare.com

URL as your API URL.


Need a more permanent solution?

Cloudflare Access Tunnel:

Set up a Cloudflare Tunnel with Access and inject your service token credentials as environment variables.

Mayhem will automatically add the necessary headers to authenticate with Cloudflare Access.

After setting the above two fields, you can either run discover or run below, and Mayhem will inject these secrets.
